1. 这项工作研究什么

Synthetic Self proposes identity continuity, historical cost and phase stability as functional requirements for long-horizon adaptation. OCB/SBT assigns delayed consequences across time/structure using an approximate causality factor, and PCF is intended to trigger reduced learning rate, freezing or rollback before instability. Explicit conceptual RSI bridge: past consequences and predicted instability are intended to govern later learning/structural changes. This is a proposed stabilizing boundary, not a verified universal theorem.
