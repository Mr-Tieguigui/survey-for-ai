6. 局限、冲突与不能推出的结论

  • 任务goal在测试期可用；训练日志未记录goal时另行推断。
  • 优化目标是动作预测代理指标，非每项编辑在线任务成功验证。
  • 反复使用同dev集并不证明对任意未来任务泛化。
  • core仅完整离线自反馈编辑系统；固定人类/专家日志是外部监督，不是在线探索。
  • 固定部署不能借用离线优化的递归核心身份。
