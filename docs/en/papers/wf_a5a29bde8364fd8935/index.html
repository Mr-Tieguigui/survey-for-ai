  • 资产技能直接整合进完整scene generator仍有下游工作表述，不把局部系统拼为全部已实现管线。
  • 固定输入snapshot→生成→冻结candidate→执行→独立检查；改动在新draft中，不动态改成功判据。
  • 下游policy训练主要单向使用合成数据，未认证学生更新反过来改善生成器。
  • 几何可达不保证任务可执行；Top-5选择指标不等于全部尝试平均成功率；sim结果不等于现实部署。
