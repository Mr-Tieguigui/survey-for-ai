1. 这项工作研究什么

LETHE rewrites processed sound into a circular buffer while a discriminator scores normalized energy features against a warm-up archive; reward-weighted random perturbations update the current FDN parameters, under coupling and spectral-radius constraints. Retained as an explicit bounded self-evaluating adaptive feedback system adjacent to RSI; persistent audio/parameters are distinct from AI-level algorithmic self-redesign.

6. 局限、冲突与不能推出的结论

  • The fixed optimizer and architecture still implement a bounded feedback loop, but the score measures energetic coherence with initial sonic DNA rather than absolute timbral quality or general AI capability. Archive and live features can drift into different normalization frames, an unverified limitation. No stronger improver, universal correctness or acceleration established. Instantaneous spectral radius below 0.99 is expressly a heuristic for time-varying feedback, not a stability guarantee.
