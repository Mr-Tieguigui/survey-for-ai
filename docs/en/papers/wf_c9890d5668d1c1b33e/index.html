EDITORIAL BRIEF / ADAS

A fixed meta-agent searches agent designs

Meta Agent Search generates, evaluates and archives target-agent implementations in a programmatic design space. Later proposals use the archive.

Evaluation conditions: Separate search conditions, selected designs and transfer evaluation.

Limits: In the reviewed configuration, target-agent functions change while the meta-agent is fixed; an archive loop alone does not establish meta-level improvement.

1. 这项工作研究什么

在当前已核配置中，系统边界为：固定元代理＋包含代码和评价的增长档案；具体更新过程为：更新档案直接条件化下一轮元代理设计和反思；档案作为改进者的持久上下文；更新状态的保留与后继使用为：跨Meta Agent Search迭代。

定点原文补充：具体问题与执行过程

把代理设计表达为可执行代码，用固定元代理根据不断扩展的目标代理档案搜索新设计。

  1. 在所给框架中编写 forward 函数；先生成设计解释与代码，再做两轮自反思。
  2. 目标代理在验证数据上评测；错误时最多五次反思修复，随后将代理与指标写入档案。

实验与选择协议：

  • 研究覆盖 ARC、数学、阅读与推理，并检验跨任务和跨模型迁移。
  • 搜索中用验证数据反馈，测试表现与搜索反馈必须区分。

解释边界：

  • 核查实例的可写空间与框架 API 有约束；代码空间的理论表达力不意味着实际搜索无约束。
  • 档案目标代理改变不等于元代理自身被更新；不能由主题相近自动连成继承。

来源：2408.08435v2；定位：§3 Meta Agent Search；§4 Experiments；Appendix C; Appendix H。本补充只登记定点描述性阅读，不扩大旧配置或数值结果的准入权限。
