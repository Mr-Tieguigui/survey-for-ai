1. 这项工作研究什么

EVE release 1.0.0 integrates a protected baseline portfolio, a calibrated bounded shortcut and exact-input checked witness memory. Candidate outputs require verification; fallback preserves a terminating baseline's binary correctness under isolation/verifier assumptions, and reuse amortization includes preparation cost. RSI-infrastructure bridge: reusable verified witnesses and learning memory reduce some later evaluation/execution work while retaining provenance and baseline fallback. Evidence reuse is not by itself recursively improving the improvement procedure.

6. 局限、冲突与不能推出的结论

  • The proofs bound cooperative logical work, not wall-clock cost of Python or blocking APIs. The registry is finite, strong specialized solvers can beat the wrapper, and the release explicitly does not demonstrate universal strict acceleration or autonomous sustained RSI.
