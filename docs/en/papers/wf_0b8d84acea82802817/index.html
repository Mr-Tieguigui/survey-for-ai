1. 这项工作研究什么

RITA represents procedural knowledge as production rules and supports agents that acquire facts or create new agents through user/external-program interaction. EP-1 observes a user performing a task, queries the user, and incrementally constructs a TASK agent; the implemented acquisition mode is distinguished from the envisioned training/debugging mode. Historical RSI bridge: an executable agent creates reusable executable rules/agents from interaction, a precursor to feedback-based program revision. No claim that EP-1 autonomously rewrites its own improvement machinery is admitted.

6. 局限、冲突与不能推出的结论

  • The current EP-1 implementation works in acquisition mode and requires user questioning; the report describes its training mode as future work. Generalizing from one or two task paths remains a stated problem. It supplies a historical program-creation mechanism rather than an autonomous recursive-improvement benchmark.
