04 / RSI examplev1.1.0 · 2026-10-23

One real field. Several ways into its knowledge.

Recursive self-improvement is the current worked example. Counts describe a fixed corpus, not global completeness or full-paper certification for every item.

RECURSIVE SELF-IMPROVEMENT

Separate feedback, gains and acceleration.

Identify what changes, feedback, retained state and later use. A fixed model does not by itself negate external feedback; a local structural loop does not prove universal RSI or sustained acceleration.

Strict primary-review plan: 533/570, with 37 source/version/locator exceptions. 509 dossiers have saved passages and 241 have evaluation details.

07 / Comparisonv1.1.0 · 2026-10-23

Compare mechanisms and the conditions behind them.

Read distinct systems along shared axes. Formal guarantees, code evolution, parameter training and program search have different evidence boundaries; this is not a cross-protocol leaderboard.

Fields come from saved configurations; missing values remain explicit. Different tasks, metrics, models and budgets cannot be ranked directly by score.
