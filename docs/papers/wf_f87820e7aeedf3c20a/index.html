1. 这项工作研究什么

在当前已核配置中，系统边界为：同模型自编辑生成策略的外层训练；具体更新过程为：当前模型提出自编辑，SFT后任务表现给外层反馈；更新生成策略继续提出自编辑；更新状态的保留与后继使用为：外层训练轮次；内层适应按实例另列。

6. 局限、冲突与不能推出的结论

  • 核心判定限外层自编辑生成策略训练。
  • 内层SFT模型用于产生奖励，不能把单实例内层适应与外层持久改进混为一个循环。
  • 复用ReST-EM训练程序不继承ReST-EM每轮从base重训设置。
