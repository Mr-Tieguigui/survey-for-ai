6. 局限、冲突与不能推出的结论

  • 固定2500 validation同时用于画像和checkpoint选择，属于适应性复用，不能当独立最终验证。
  • 答案由构建流程/已有标签提供；当前模型过滤不等于模型自行创造真值。
  • 外部任务评估保留官方可回答子集口径；不同基础模型和类别可能回归，非普遍收益。
  • 训练闭环不能扩张为部署在线自改；optimizer每轮重启不否定policy状态回流。
