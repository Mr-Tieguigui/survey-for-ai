1. 这项工作研究什么

The cognitive-substrate proposal combines local metabolic processing, recursive global self-representation, structural constraints and autonomous memory prioritization. Its described hybrid control passes performance information upward and architectural constraints downward, aiming to coordinate local structural adaptation without a separate training/inference phase. Explicit RSI-concept bridge: internal self-representation and performance feedback are proposed to govern later architectural and memory changes. No fully implemented autonomous RSI system or guaranteed stability is inferred.
