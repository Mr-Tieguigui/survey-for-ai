## 1. 这项工作研究什么
The local multi-scale RSI specification separates fast evolutionary search, expanded medium testing and a slow shadow reference. Promotion combines score improvement, anchor nonregression, adversarial stress, success density and trace/quantization checks under an immutable core; consolidation manages adapters. Direct RSI-concept bridge: validated program/strategy/adapter changes are intended to persist across fast/medium/shadow timescales, while protected reference/core constrain future proposals. Hardware suggestions are design assumptions, not measured configurations.

## 6. 局限、冲突与不能推出的结论

- This is an architectural specification for restricted programming/algorithm/math domains, frozen base models and lightweight adapters, not a verified deployment benchmark. Oracle failures, coordination cost, verification latency and heuristic top-N quantization invariance remain explicit limitations.
