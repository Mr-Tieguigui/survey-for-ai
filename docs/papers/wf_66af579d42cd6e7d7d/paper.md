## 1. 这项工作研究什么
Narsi Regression proposes explicit mutations of representations/concepts, evaluated by quality/energy criteria and selectively retained in persistent learner state. It treats merge, split, hierarchy and relation proposals as hypotheses whose utility depends on prediction, transfer, reuse and retained distinctions. Explicit conceptual RSI bridge: current knowledge, memory and evaluation guide changes to representations used in subsequent adaptation. No empirical recursive-improvement or universal safety result is admitted.
