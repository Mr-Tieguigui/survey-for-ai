1. 这项工作研究什么

在当前已核配置中，系统边界为：固定四接口数据preparator、可修改adapter、pilot运行与评估报告组成数据准备系统；具体更新过程为：每轮把基础preparator与当前adapter重新编译，pilot报告经Trace触发编码代理修订adapter，下一轮使用该adapter再次准备/评价数据；更新状态的保留与后继使用为：跨pilot轮保留adapter；不是把单条回答当成改进状态。
