6. 局限、冲突与不能推出的结论

  • distillation与self-distillation是两种数据重标注变体。
  • 离线训练关系不能赋予部署单问题rollout持续跨题学习。
  • 与Self-Refine的横向对照限指定训练/推理边界，不能认定原任务与RISE适配基线完全同配置。
  • RISE的非oracle测试模式不表示离线训练数据构造不使用正确性奖励或教师。
