R$^2$ Flow: Recursive Self-Improvement via Recursive Skill Evolution

关系：contrasts_system_boundary_with · r2_skillvine_r2flow_12 · 当前展示权限：primary_supported。 SkillVine在可回溯版本图中比较主干和旁支的验证准确率，并以主干结果控制旁支编辑粒度；R² Flow则把技能库、图、策略/流参数和验证计数作为阶段状态，用可靠性后验及流诊断选择技能编辑，经配对回放的多指标非劣门控后进入下一阶段重训。两者共享技能库迭代这一比较轴，具体搜索和接受机制不同。

关系边界：仅为策展者的双端机制比较；未取得直接继承、代码复用或同一任务同预算性能比较证据。R² Flow的固定阶段递归不能据此解释为更新算子自身代码修改。
