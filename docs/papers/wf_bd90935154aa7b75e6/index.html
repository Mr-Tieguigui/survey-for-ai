1. 这项工作研究什么

在当前已核配置中，系统边界为：当前生成策略与奖励过滤轨迹；具体更新过程为：Grow从当前策略采样，Improve微调当前最好策略，再以更新策略Grow新数据；更新状态的保留与后继使用为：跨Grow/Improve轮次。
