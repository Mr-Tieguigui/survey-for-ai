6. 局限、冲突与不能推出的结论

  • Intensionality or isolated opposite outcomes alone is explicitly insufficient. The instrumentation class is an existential witness, not all rewrites; function-preserving refactoring and fine-tuning/pruning/quantization are not covered by that class. Resource intractability is separate from decidability, and classifying all disruptive transformations/categorical unification is open.
