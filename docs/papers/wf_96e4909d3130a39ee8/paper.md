## 1. 这项工作研究什么
The RPG orchestration architecture monitors contradiction/novelty/stagnation, reflects on degradation, creates a successor specification with distilled state and failure exclusions, and deploys it with lineage metadata. Configurable heuristics and cooldowns trigger succession; predecessor sessions and quality metrics are archived. Direct bounded system bridge: evaluated experience changes successor prompts/specifications and inherited memory used in future sessions without requiring model weight changes. Persistent handoff can support improvement but does not establish it automatically.

## 6. 局限、冲突与不能推出的结论

- Evaluator quality depends on model-based heuristics. Optimal state distillation is not formalized, successor comprehension checks are not fully implemented, and longitudinal infrastructure is still needed to determine whether cross-session quality actually improves. Session succession is not itself a measured RSI gain.
