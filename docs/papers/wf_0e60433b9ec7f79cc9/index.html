6. 局限、冲突与不能推出的结论

  • A challenger-relative optimality bug is not global optimality. Baseline assumptions are deterministic policy/dynamics; the stochastic extension instead uses repeated rewards and a one-sided statistical test. Selected evidence supports testing plus a bounded offline repair step, not indefinitely recursive improvement of the tester/improver.
