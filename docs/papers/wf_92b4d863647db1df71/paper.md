## 1. 这项工作研究什么
Civilizational Memory proposes neural coordinate routing into a deterministic archive with hierarchical IDs. ID mitosis subdivides overloaded/divergent knowledge blocks, while a coherence firewall rejects disconnected or structurally inconsistent submissions and retains rejected material outside core retrieval paths. Explicit RSI-infrastructure bridge: memory resolution and access structure change through load-triggered ID subdivision, influencing later retrieval. This is adaptive knowledge infrastructure, not demonstrated autonomous improvement of its own learning algorithm.
