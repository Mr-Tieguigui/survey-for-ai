1. 这项工作研究什么

在当前已核配置中，系统边界为：单个输入的答案与反馈；具体更新过程为：固定LM及三类提示迭代修订同一答案，停止后返回最终输出；更新状态的保留与后继使用为：单个最终输出内部。

6. 局限、冲突与不能推出的结论

  • 所有模块由固定同一LM提示执行，单输入内历史不认证跨最终输出持久学习。
  • 数学推理附录A15.p5使用正确标签决定循环阶段；无额外模型训练不等于所有实验没有oracle反馈。
