6. 局限、冲突与不能推出的结论

  • v2大幅改写v1；不沿用v1跨proposal累积wealth及旧实验认证说法。v2每opened attempt冻结对象并独立建立条件有效证书，跨attempt只累计错误预算。
  • 条件有效性和可预测、逐路径可和预算是前提；固定目标、真实state binding才有单调性推论，不能认证任意分布漂移或未来utility。
  • SGM不证明conditional证书输入对任何生成器自然成立；不修复污染确认数据或错设目标。
  • 旧CIFAR100的5.51pp不是30-pair配对效果（v2记1.538pp）；旧CIFAR10/RL图未认证接受，不算额外certified improvement。
  • CTHS只是可选spending，不具普遍功效优势；SGM与等价standard spending实现一致，不形成优越性结论。
  • 官方landing的v2日期与旧题名/摘要和versionedHTML v2新正文存在不一致；本卡只绑定所读HTML v2，PDF/TeX内容一致性待核。
  • 2attempt单轨迹，不估计长期FWER或跨seed训练规则保证；second rejected candidate不能据拒绝说成有害。
  • 确认在固定49,968图池上新iid有放回索引抽样，目标仅该有限池准确率；不是外部泛化保证，重计旧样本不符合模型。
  • 确认与最终audit内容hash分离和近重复审查不证明无语义近重复；P2设计经过先前development失败修订。
  • 不把65.36→77.35的descriptive audit用于重新选择或补发接受证书。
  • 仅实读官方摘要作角色和范围判读，未核全文方法、实验、定理及数值；不得直接支持技术回答或继承关系。
