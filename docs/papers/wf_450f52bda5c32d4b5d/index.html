1. 这项工作研究什么

EvoMind describes a durable governed skill lifecycle with separated discovery/sandbox, causal/regression evidence and a single promotion authority. Only Stack C activation creates canonical runtime registration; evidence hashes, scope and predecessor state accompany transactional transitions, revocation and fail-closed states. Direct bounded RSI-system bridge: experience-derived skills persist through evidence/approval lifecycle into future runtime capability, with canonical registration and revocation. This is governed capability compounding, not established AGI.
