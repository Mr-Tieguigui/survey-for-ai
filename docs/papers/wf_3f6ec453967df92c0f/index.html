1. 这项工作研究什么

GCAP uses Hoare/separation logic to treat runtime machine code as mutable data for modular von Neumann reasoning. The body describes mechanized Coq soundness and certified code-manipulation examples, including an x86 boot loader and MIPS examples; self-replication copies and executes successive code blocks. Optional RSI verification substrate: reasoning about changing code memory may support constrained self-modification, without an empirical RSI agent or measured acceleration.
