1. 这项工作研究什么

FNE-AXIOMESH defines executable cognitive state and behavioral equivalence under protected observations and all allowed operator words. A finite-linear specialization compiles a quotient preserving frozen execution; candidate growth must account for external observations, storage, discovery and repair rather than rank alone. RSI-infrastructure bridge: as the allowed operator family grows, memory/reconstruction obligations grow, constraining later representation changes and persistent offspring. Backend correctness is distinct from improved ability to design the next improvement.

6. 局限、冲突与不能推出的结论

  • The finite exact model is not arbitrary intelligence. In the capability curriculum the operator sequence is externally supplied, so accurate reconstruction during library growth does not show an improving transformer inventing better operators. Optimized conventional worklists can match reported row-product counts.
