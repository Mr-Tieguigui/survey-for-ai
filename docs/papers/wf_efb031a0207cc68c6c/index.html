1. 这项工作研究什么

The self-referential assessment in §3.4 compares each essay's analytic trait deviations within that learner's own profile, turning unusually strong/weak traits into two classification tasks. It standardizes reference and predicted scores, uses a one-standard-deviation target threshold, and reports prevalence-normalized F0.5 prioritizing precision. Original-body scope exclusion: within-learner reference is not an evaluated agent self-improvement process. Exclusion is topical, not a claim that the study lacks feedback.
