6. 局限、冲突与不能推出的结论

  • 通过验证指源序列未来item排名达标，不是所提item自身必须排top-tau。
  • 不确定度是目标分量BALD式评分，不是完整互信息；B在看分数前固定。
  • DA-RSIR每轮从随机初始化重训；不能因参数重启否认模型/数据回流，也不能误报为FT连续参数。
  • 5轮单seed轨迹在第4轮后下降，不支持单调收益；离线ID结果不等于线上工业部署。
