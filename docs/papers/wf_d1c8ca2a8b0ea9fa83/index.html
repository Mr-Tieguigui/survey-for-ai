6. 局限、冲突与不能推出的结论

  • 每研究者仅一个episode，模型和harness绑定，不能分离独立组件效果。
  • 开发最好不等于sealed最好；公共任务抽样Random120是强基线。
  • 输出截断、预算耗尽和少量高权重题可影响结果；固定13候选/14目标面板不能证明未来模型的广泛效度。
