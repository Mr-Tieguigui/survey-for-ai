1. 这项工作研究什么

CDIL-RSI proposes alternating diagnostic distinction and corrective integration, followed by hysteresis damping and pruning of degrading updates. Trace density is intended to regulate stagnation, exploration and recursion depth, while operator-controlled local state and scalar-only sharing preserve a sovereignty design objective. Explicit conceptual RSI bridge: diagnosed outcomes produce candidate changes to configuration governing later cycles. Current evidence defines the loop rather than demonstrating improved recursive-learning productivity.
