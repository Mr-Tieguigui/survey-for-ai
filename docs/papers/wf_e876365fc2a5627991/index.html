6. 局限、冲突与不能推出的结论

  • 10步受控实验不能推所有规模/训练分布永久免collapse；失败维度和任务能力须分开。
  • 筛选不需human/AI标签，不代表无需真人语料；原文§8几乎所有选中文档为真人。
  • 高perplexity不是事实正确/高质量保证，随机噪声和极端分布外文本需另控。
  • §4 AI段有M_j+1生成数据的文字下标笔误，按Algorithm1与邻近描述使用M_j。
